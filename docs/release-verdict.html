Begona odam parolsiz akkauntga kiradi — agar server sozlamalari faqat ishga tushirishda berilsa

src/lib/env.ts:187 · src/app/api/dev/confirm-link/route.ts:31

Natijada production himoyasi umuman ishlamaydi: sinov uchun yozilgan soxta auth ishlayveradi, va faqat dasturchilar uchun mo'ljallangan manzil istalgan odamning parol tiklash tokenini qaytaradi.

Zaxiradan tiklash orqali boshqa mijozning loyihasiga yozib bo'ladi

src/lib/settings/backup.ts:301–355

Tiklashda faqat projects qatorlariga to'g'ri egasi yoziladi. Qolgan 17 ta jadval fayldan kelgan projectId ni o'zgartirmasdan qabul qiladi. Ya'ni fayl ichiga begona loyiha IDsini yozib, o'sha loyihaga qator qo'shib bo'ladi.

# hujumchi o'z akkauntidan tiklash qildi.
# fayl ichida: projectId = qurbonning loyihasi

SELECT c.objective, p.name, p."workspaceId"
  FROM content_items c JOIN projects p ...
